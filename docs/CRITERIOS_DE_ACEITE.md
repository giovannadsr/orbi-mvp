# Critérios de aceite do MVP

## Fluxo principal
- [ ] O usuário consegue criar uma conta demonstrativa usando dados fictícios.
- [ ] O usuário consegue entrar e sair da sessão demonstrativa.
- [ ] O usuário consegue selecionar interesses.
- [ ] Os interesses permanecem após recarregar a página.
- [ ] O usuário consegue localizar conteúdos por busca e filtro.
- [ ] O usuário consegue abrir e ler um conteúdo.
- [ ] O usuário consegue marcar o conteúdo como iniciado, em andamento ou concluído.
- [ ] O progresso permanece após recarregar a página.
- [ ] O painel apresenta o progresso de forma compreensível.

## Qualidade
- [ ] A aplicação funciona em navegador desktop atualizado.
- [ ] O layout continua utilizável em tela estreita.
- [ ] Os controles principais podem ser identificados e utilizados por teclado.
- [ ] Mensagens e botões comunicam claramente o resultado das ações.
- [ ] Nenhum dado real ou sensível é usado na demonstração.

## Registro de teste
Para cada cenário, anotem: data, responsável, navegador, passos executados, resultado (passou/falhou), evidência e Issue relacionada.
